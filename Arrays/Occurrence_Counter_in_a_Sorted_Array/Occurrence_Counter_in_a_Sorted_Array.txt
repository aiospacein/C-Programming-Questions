Count occurrences of a number in a sorted array.

WTD: For a given number and a sorted array, iterate through the array to count the number of times that particular number appears.

(e.g.: I/P: [1, 2, 2, 2, 3], 2, O/P: 3 )

Approach	                            Time	    Extra Space	Verdict
Linear scan	                            O(n)	    O(1)	🥈 Simple
Binary search: first + last occurrence	O(log n)	O(1)	🥇 Best
Hash/frequency table	O(n) average	O(n)	    ❌ Unnecessary
