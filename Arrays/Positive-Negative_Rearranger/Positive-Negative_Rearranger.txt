Rearrange positive and negative numbers in an array.

WTD: Sort the array such that all the positive numbers appear before the negative ones, while maintaining their original sequence.

(e.g.: I/P: [1, -2, 3, -4, 5, -6], O/P: [1, 3, 5, -2, -4, -6] )

Approach	                Time	Extra Space	Stable	Verdict
Auxiliary array + 2 scans	O(n)	O(n)	✅	🥇 Fastest
In-place shifting	        O(n²) worst case	O(1)	✅	🥈 If memory is critical
Swap-based partition	    O(n)	O(1)	❌	Doesn't satisfy order requirement
