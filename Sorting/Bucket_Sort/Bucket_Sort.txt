Bucket Sort:


WTD: Sort floating-point numbers using Bucket Sort.

Bucket Sort: Distributes elements into buckets, sorts individual buckets, and then concatenates them.

(e.g.: I/P: [0.897, 0.565, 0.656, 0.1234, 0.665, 0.3434]; O/P: [0.1234, 0.3434, 0.565, 0.656, 0.665, 0.897])


Bucket Sort
A distribution-based sort that partitions elements into several empty "buckets," sorts each bucket individually (often with insertion sort), and then concatenates the buckets. Ideal for uniformly distributed floating-point numbers.
