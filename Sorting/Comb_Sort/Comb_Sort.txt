WTD: Sort an array using comb sort.

Comb Sort: A variant of bubble sort that eliminates turtles, or small values near the end of the list.

(e.g.: I/P: [8, 4, 1, 14, 8, 2, 9, 5]; O/P: [1, 2, 4, 5, 8, 8, 9, 14])


Comb Sort
An improvement over Bubble Sort that eliminates small values near the end of the array ("turtles") by comparing elements separated by a variable gap size, which shrinks by a factor (usually 1.3) each pass until it reaches 1.
